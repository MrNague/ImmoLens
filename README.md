# ImmoLens by Mr. Nague

A property-price ML engineering project owned and developed by Pascal Nague.

## Current state

This foundation release repairs the Python setup, synthetic training and training/serving consistency. **All training prices are generated examples, not observed property prices.** Holdout metrics measure the synthetic task only. This project does not yet provide a validated market valuation.

The existing `app.py` is a legacy Streamlit demonstration. It still generates its own illustrative outputs and is **not connected to this model/API**. API verification and replacement frontend integration are the next work packages.

## Local setup

Use **Python 3.11 or 3.12**. Docker uses Python 3.12. Check your interpreter before creating the environment.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe api.py
```

Use `py -3.11` instead if Python 3.11 is installed. These commands do not require PowerShell activation or execution-policy changes.

Linux/macOS/WSL (with Python 3.11 or 3.12 as `python3`):

```bash
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pip check
.venv/bin/python -m pytest -q
.venv/bin/python train.py
.venv/bin/python api.py
```

For runtime-only installation, use `requirements.txt`; `requirements-dev.txt` adds pytest and the HTTP test client.

API documentation: http://localhost:8000/docs. `GET /health` returns 200 only after a compatible complete model bundle loads. Train before starting or restarting the API.

## Training and artifacts

```bash
python train.py --samples 2000 --seed 42 --reference-year 2026 --output-dir modelle
```

- `modelle/pipeline.joblib`: shared feature function, fitted scaler and Random Forest together.
- `modelle/metadata.json`: feature schema, reference year, checksum, dependency version, synthetic coverage and measured holdout metrics.
- `mlruns/`: local MLflow experiment records. `MLFLOW_TRACKING_URI` can select another tracking backend.

The generator uses a local seeded RNG, float price arithmetic, and valid bedroom/room relationships. The split is an 80/20 random synthetic holdout. It is not temporal market validation. The scaler is fitted on training rows only. The model excludes generated postal codes and all target-derived values.

The reference year is explicitly stored with the fitted feature transform. Training and serving do not derive age from different wall-clock years. Retrain after changing the reference year, feature schema, or scikit-learn version.

**Migration:** old `random_forest_model.pkl`, `scaler.pkl` and `feature_cols.pkl` files are no longer loaded. Run `python train.py` to generate the new bundle. Missing, partial, mismatched or incompatible bundles leave the API unready with HTTP 503. Only load trusted artifacts generated by this project.

## Existing API contract

`POST /predict` accepts the existing German field names:

```json
{
  "flaeche": 85,
  "zimmer": 4,
  "schlafzimmer": 2,
  "etage": 2,
  "stadt": "Berlin",
  "plz": "10115",
  "baujahr": 2010,
  "entfernung_bahn": 0.5,
  "garten": 1,
  "balkon": 1
}
```

Supported synthetic scope: six cities (Berlin, Hamburg, München, Köln, Frankfurt, Stuttgart), 30–250 m², 1–8 rooms, 0–5 bedrooms no greater than rooms, floors 0–9, construction years 1950–2022 and station distance 0–5 km. `plz` is optional and ignored by the model; no real postal geography is claimed.

Response fields retain `preis_estimate`, `preis_formatiert`, `preis_pro_m2`, `modell` and `features`. New metadata identifies `data_mode: "synthetic"`, target, currency, model ID and reference year. **`interval_min` and `interval_max` are now null:** the former arbitrary ±10% band was not a calibrated prediction interval. Clients must handle nulls. Out-of-scope or invalid inputs return HTTP 422; an unavailable bundle returns HTTP 503.

The proposed `/v1` API and replacement frontend belong to subsequent work. CORS configuration should be added for the chosen frontend origin when connecting it; this foundation API does not enable unrestricted browser origins.

## Docker

```bash
docker compose --profile training run --build --rm train
docker compose up --build api
```

The API publishes port 8000. Run the legacy UI separately, if needed, with `docker compose up --build streamlit`; only that service publishes port 8501. The Docker image starts one API process by default. Its model bundle is provided by the mounted `modelle` directory.

## Checks

```bash
python -m pytest -q
python -m pip check
```

Regression tests exercise the generator crash, repeatability, shared age/city features, target exclusion, artifact round trips, API/pipeline parity, invalid scope, and fail-closed readiness. CI runs the suite on Linux and Windows with Python 3.11 and 3.12. Docker needs a separate build/runtime check on a machine with Docker available.
